How matches are selected

Same disc level, separate study, reference grade agrees with the fixed ensemble. Rank by full-field appearance across three axial T2 slices (75%) and the entire sagittal image (25%). When only one query plane is verified, both studies use their center plane plus the sagittal view. The fixed weights are a design hypothesis. Reader agreement on similarity is untested.

Scope and reading protocol

Review all five levels, inspect adjacent slices, compare reference examples when useful, and record an independent grade or insufficient images per level. Blind read hides model calls and reference cases. The reader worksheet contains only your entries. It is a research record.

Reference agreement uses equal model weights, severe threshold 50%, no deferral. Axial levels use existing bilateral RSNA subarticular landmarks. Missing or inconsistent landmarks can exclude a level. An extracted slice may miss the plane of greatest narrowing. The preview does not assess foraminal or recess stenosis, clinical urgency, or treatment eligibility.

Markers indicate projected RSNA reference locations. Axial examples use the same named level and relative stack position. These are independent examinations.
